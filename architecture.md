
# ApplyForOnce Architecture

## Overview

ApplyForOnce is an AI-powered job discovery, application management,
and career intelligence platform.

## Architecture Style

Microservices architecture.

## Core Technologies

- Java 21
- Spring Boot
- Maven
- PostgreSQL
- Docker
- GitHub Actions

## Planned Capabilities

- User authentication and profiles
- Company watchlists and job discovery
- Application tracking and Gmail integration
- Developer profile integrations
- AI career assistant
- Resume analysis and tailoring
- Interview preparation
- Salary intelligence
- Referral assistance

## Architecture Principles

- Clear service boundaries
- Independent data ownership
- Secure external integrations
- Automated testing
- Configuration through environment variables
